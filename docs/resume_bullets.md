# Resume Bullets — FinSight

Use 3–4 of these. Every number is real and measurable from the project (no invented
performance metrics). Adjust wording to fit your resume's style.

## Recommended set (concise)

- Built an end-to-end **customer & campaign analytics** pipeline on ~22,000 synthetic
  transactions (1,500 customers, 30 campaigns) using **Python, Pandas and SQLite**,
  with a single seeded config for full reproducibility.
- Wrote **18 business SQL queries** (CTEs, window functions, ranking) for revenue,
  retention and campaign performance, and built a **data-quality pipeline** that
  detects and reports six classes of data defects before analysis.
- Segmented customers with an explainable **RFM model** (4 segments) and evaluated
  campaigns on **CTR, redemption rate and ROI**, surfacing that several
  high-redemption campaigns were margin-negative due to discount depth.
- Added statistical **anomaly detection** (log-space IQR + month-over-month change)
  and a rule-based **next-best-category** recommender; used the **Gemini API** to
  narrate only Python-verified metrics; visualised results in a **3-page Power BI**
  dashboard. Backed by **20 automated tests** (pytest).

## Alternative one-liner (if you only have room for one)

- Built a reproducible customer & campaign analytics project on synthetic data —
  Python/Pandas cleaning, 18 SQL analytics queries, RFM segmentation, campaign
  ROI analysis, anomaly detection and a 3-page Power BI dashboard, with an
  LLM used only to summarise verified metrics.

## Skills this project evidences

Python · Pandas · NumPy · SQL · SQLite · Excel (XLOOKUP/SUMIFS/COUNTIFS/pivots) ·
Power BI · data cleaning · RFM segmentation · campaign analytics · anomaly
detection · responsible LLM use · reproducible pipelines · pytest.

## What NOT to say
- Don't call it "enterprise", "production-grade", or a "banking platform".
- Don't quote business outcomes (e.g. "increased revenue 20%") — the data is synthetic.
- Do say "synthetic data" if asked; it's a strength, not a weakness (see interview prep).
